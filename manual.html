1About the system

This is an online multiple-choice exam system built with HTML, CSS and JavaScript only. It has two kinds of users:

  • Administrator – registers students and gives them a username and password, uploads the exam from a PDF, sets the exam time, resets passwords and views results.
  • Student – logs in, takes the timed exam, submits it and sees the result. A student cannot repeat the exam.

The default administrator login is admin / admin123. Change it the first time you log in.

3Publishing on GitHub

  1. Go to github.com, sign in, click + → New repository. Name it drvu-exam, choose Public, click Create repository.
  2. Click uploading an existing file. Drag in index.html, style.css, script.js, config.js and exam-data.js (the files themselves, not the folder). Click Commit changes.
  3. Open Settings → Pages. Under Build and deployment choose Deploy from a branch, branch main, folder / (root), then Save.
  4. After 1–2 minutes a link appears, such as https://yourname.github.io/drvu-exam/. This is the link you give to students.

4Letting students use any device

Data is saved in the browser. For students to log in on their own phones or on center computers, choose one of the two options below.

Option A – Firebase (automatic, recommended)

Accounts, progress and results are shared by all devices. No result codes are needed.

  1. Go to console.firebase.google.com → Create a project.
  2. Open Build → Realtime Database → Create database → Start in test mode.
  3. Open the Rules tab, paste the text from firebase-rules.json and click Publish.
  4. On the Data tab copy the database address, for example https://drvu-exam-default-rtdb.firebaseio.com.
  5. Open config.js and paste the address: 
    window.DRVU_CONFIG={
  cloudUrl:'https://drvu-exam-default-rtdb.firebaseio.com'
};
  6. Upload the changed config.js to GitHub (replace the old one).
  7. Open your site. The login page must say ● Server connected. Log in as admin once; the top bar shows ● Synced.

Option B – Publish to GitHub (no database)

Student accounts and questions are published as exam-data.js. Results come back as result codes.

  1. Create a token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Choose only your exam repository and set Contents: Read and write. Copy the token.
  2. In the system go to Account → Auto-publish to GitHub. Enter the repository as username/repository, the branch main and the token. Click Save details.
  3. After you register students or change the exam, a banner says Changes are not published to students yet. Click Publish to GitHub now. Students see the update in 1–2 minutes.
  4. When a student submits, the result page shows a result code. The student sends it to you (Telegram, WhatsApp or email). Go to Results → Import result codes, paste the codes (one per line) and click Import. Scores are recalculated from the answers.
Without GitHub publishing you can also click Account → Download exam-data.js and upload the file to the repository by hand.

5Administrator guide

Log in and change your password

Open the site and log in with admin / admin123. Go to Account, enter the current password and a new password, then Save. To open the admin panel on a device that already holds student data, add #admin to the end of the link.

Register students (Students tab)

Enter the full name, a username and a password, then click Register. Give each student their username and password. Use the Search box to find a student.

  • Edit – change the student’s name.
  • Reset password – set a new password.
  • Delete – remove the student and their result.

The status shows Not started, In progress or Submitted.

Set up the exam (Exam setup tab)

  • Title, Time (minutes) and Exam status (Open or Closed). Students can start only when the exam is Open.
  • Show answers after submit – choose Yes to let students review their answers.
  • Click Save settings.

Upload questions

Choose a PDF in Upload questions from PDF, or paste the text in the box and click Parse text. Check the questions below, fix any text, and choose the correct answer for each. Use + Add question to add one by hand. PDF reading needs an internet connection and a text-based PDF (not a scanned image).

View results (Results tab)

  • See each student’s score and percentage; the dashboard shows the average.
  • Details – each answer compared with the correct answer.
  • Allow retake – deletes a result so the student can sit the exam again.
  • Download CSV (opens in Excel) and Print.

Backup

In Account → Backup and restore, click Download backup regularly. You can restore it on another computer or merge results from another computer.

6Exam PDF format

Write each question with a number, options A–D and an answer line:

1. Which language is used to style web pages?
A. HTML
B. CSS
C. SQL
D. Java
Answer: B

2. Android apps are mainly written in:
A. Kotlin
B. COBOL
C. Pascal
D. Fortran
Answer: A

If a PDF has no Answer: lines, choose the correct answers in the editor after uploading.

7Student guide

  1. Open the exam link on a phone or computer.
  2. Enter the username and password given by the administrator, then Sign in.
  3. Read the number of questions and the time allowed, then press Start exam. The timer cannot be paused.
  4. Choose one answer for each question. The bar at the top shows how many you have answered and the time left. If the page is refreshed or you log in on another device, the exam continues with your saved answers.
  5. Press Submit exam. When the time ends, the exam is submitted automatically.
  6. Your score appears. You cannot take the exam again unless the administrator allows it.
  7. If your center uses result codes, copy the code shown on the result page and send it to the administrator.

8Troubleshooting

ProblemSolution
Page has no design or buttons do nothingFiles are not together or names are wrong. Keep all files in one folder with lowercase names. A red message at the top names the missing file.
“No exam data or server found”No exam-data.js was published and no Firebase address is set. Use Option A or B in section 4.
“Cannot reach the server”Check the address in config.js (no extra slash) and that the Firebase rules were published.
Student account not found on a phonePublish the latest accounts (Option B) or check the login page says Server connected (Option A). Wait 1–2 minutes after publishing.
“Wrong password”Check the password in the Students tab. Capital letters in the username do not matter.
PDF does not loadUse a text-based PDF with the format in section 6, check internet, or paste the text instead.
Forgot admin passwordOpen the browser console (F12) and run localStorage.removeItem('drvu'), then reload. This deletes local data, so keep backups.

9Security notes

  • Change the default admin password before the exam.
  • Student passwords and the answer key are stored in exam-data.js or in Firebase, so a technically skilled person could read them. This system is suitable for classroom and mid-exam use, not for high-stakes testing.
  • Keep your GitHub token private and limited to the exam repository. Delete it when you finish.
  • Without Firebase, the “one attempt only” rule applies per device.
